# @apexops/testkit

Fixtures and deterministic helpers for testing APEX vNext contracts, workflows,
and qualification scenarios.

## Install

```bash
npm install --save-dev @apexops/testkit
```

## Use

```ts
import { requirementsFixture, runFixture } from "@apexops/testkit";
```
