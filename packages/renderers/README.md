# @apexops/renderers

Deterministic renderers for APEX vNext requirements, previews, approvals,
resource inventories, and workflow status documents.

## Install

```bash
npm install @apexops/renderers
```

## Use

```ts
import { renderRequirements, renderDeploymentPreview } from "@apexops/renderers";
```

Rendered documents are review projections. The source APEX artifact remains
authoritative.
