# @apexops/contracts

Versioned TypeScript contracts and JSON Schemas for APEX vNext persisted state,
workflow artifacts, evidence, and client projections.

## Install

```bash
npm install @apexops/contracts
```

## Use

```ts
import { RequirementsV1Schema, type RequirementsV1 } from "@apexops/contracts";
```

The package exports TypeBox schemas, their TypeScript types, and JSON Schema
files under `schemas/`. It is intended for APEX runtime packages and integrations.
