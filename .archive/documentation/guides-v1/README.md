# Superseded vNext Guides

## Status

This archive preserves the first extracted vNext guide set. The guides were replaced by vNext-only tutorials, how-to
guides, explanations, and references under `docs/`.

The archived pages mixed procedures, concepts, reference material, historical qualification claims, and stale client or
cloud status. They are provenance only and are not active product documentation.

## Replacement Owners

- `docs/tutorials/` owns learning-oriented local evaluation.
- `docs/how-to/` owns task procedures.
- `docs/explanation/` owns architecture and trust-boundary concepts.
- `docs/reference/` owns commands, tools, support, configuration, IaC, and qualification facts.

## Rollback

Restore an archived page only after removing its replacement, retargeting all links and documentation tooling, and
proving the old claims against current vNext source authorities.
